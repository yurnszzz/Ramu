# Batas materi FE Basic

Ringkasan dari materi dan instruksi final project yang tersedia secara lokal. File kelas asli tidak dimasukkan ke GitHub.

| Materi | Penerapan Ramu |
| --- | --- |
| HTML dasar | Dokumen, heading, paragraf, daftar, tautan, form semantik |
| CSS dasar dan lanjutan | Selector, box model, warna, tipografi, pseudo-class, pseudo-element |
| Layouting | Flexbox, grid, spacing, layout responsif |
| JavaScript dasar | Variabel, array/object, operator, conditional, loop, fungsi |
| DOM dan event | Pencarian, filter, detail materi, pratinjau sesi, pergantian langkah, dan ringkasan dari isian mentor |
| Responsive | Viewport meta, media query, pengujian ponsel/tablet/desktop |
| Git dan GitHub | Commit nyata, branch per tahap, push, review PR, merge |

Framework diizinkan secara opsional oleh tugas kelas, tetapi keputusan Ramu adalah **HTML/CSS/JavaScript native**. Jangan menambahkan framework, build system, backend, database, akun, API data, penyimpanan browser, timer, atau notifikasi.

T01 memakai HTML dan CSS untuk tiga halaman. Pada T02, event `input` dan `change` membaca kata kunci serta kategori. JavaScript menyaring array lokal, memperbarui daftar yang terlihat, dan menampilkan detail materi yang dipilih.

Pada T03, pilihan template mengisi editor dan nilai form ditampilkan di pratinjau. Pada T04, satu indeks menandai langkah yang sedang dipandu. Tombol sebelumnya dan berikutnya berhenti di batas empat langkah. Editor dan mode pandu bergantian tampil dalam dokumen yang sama sehingga isian form tetap tersedia. Mentor dapat menyalin teks ringkasan yang disusun dari rancangan, persiapan, dan evaluasi pertemuan.

Kriteria tugas kelas mencakup proyek individu, minimal dua halaman/section, layout responsif, interaksi JavaScript DOM, dan repository publik. Ramu menargetkan tiga halaman; seluruh kriteria baru lengkap setelah tahap interaktif dan finalisasi. Batas pengumpulan yang diberikan: 20 November 2026, 23:59 WIB melalui Dignition.
