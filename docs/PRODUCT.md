# Produk Ramu

## Platform dan stack

Website statis untuk browser desktop dan ponsel, memakai HTML, CSS, dan JavaScript native. Tidak ada build atau dependensi runtime. Batas ini ditetapkan dalam PRD dan prompt proyek, lalu pengguna menyetujui melanjutkan dari referensi tersebut.

## Pengguna dan tugas

Mentor pembinaan Islam lintas lembaga dan komunitas menyiapkan materi, menyusun pertemuan, memandu diskusi, dan mencatat evaluasi sementara. Bahasa antarmuka Indonesia.

## Tahapan

T01 membangun tiga halaman, navigasi, dan fondasi visual. Bank materi interaktif, editor sesi, serta panduan dan catatan dinamis dikerjakan bertahap sesudahnya. Rincian ada di `planning/TASKS.md` dan `planning/PRD.md`.

## Batas tetap

Tanpa akun, backend, storage browser, API, pengingat, atau pembuatan hukum agama. Jangan menyatakan materi telah direview tanpa bukti. Draf pada tahap interaktif tidak bertahan setelah reload atau perpindahan halaman. Target aksesibilitas: navigasi keyboard, fokus terlihat, teks isi minimal 16px, dan layout tanpa overflow pada 320–1440px.

## Identitas

Gunakan desain papan referensi: teal, kertas krem, sage, aksen emas, skeuomorphism halus. Wordmark HTML dipakai selama persetujuan logo final belum ada. Ramu tidak menyatakan afiliasi resmi dengan lembaga tertentu.
