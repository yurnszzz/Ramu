# Mulai dari sini

Ramu adalah final project FE Basic. Dokumen ini mengarahkan pengerjaan bertahap sesuai [PRD](planning/PRD.md).

1. Baca [AGENTS.md](AGENTS.md), [batas materi](docs/COURSE_BASELINE.md), dan [desain](docs/DESIGN.md).
2. Ikuti [CODEX_START](planning/CODEX_START.md) dan status di [TASKS](planning/TASKS.md).
3. Siapkan referensi desain lokal bila diperlukan melalui [SKILLS_SETUP](docs/SKILLS_SETUP.md).
4. Kerjakan satu tahap per branch dan PR, lalu periksa [QA](docs/QA.md).
5. Review dan merge PR tahap tersebut sebelum mulai tahap berikutnya.

Paket awal hanya memuat PRD, prompt, start-here, design board, dan calon aset SVG. Struktur dokumentasi dilengkapi dari referensi tersebut; file kelas asli dan catatan lokal tidak diterbitkan. Salinan PRD dan design board berada di `planning/`. Calon logo belum digunakan sampai ada persetujuan.

Lihat [README](README.md) untuk keadaan implementasi dan cara membuka website. Website ini tidak memerlukan akun, API key, backend, atau instalasi framework.
